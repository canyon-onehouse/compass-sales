# Canonical visual direction: the current sparse generation

The prototype archive (`uploads/Compass Design Website.zip`) contains two page generations: the current sparse pages (homepage: hero gallery → motto → project CTA → footer) and a fuller v1 (`Compass Homepage v1.html`, `Projects v1.html`: approach tenets, featured-work rows, testimonial, studio teaser, inline inquiry). We decided the **current sparse generation is canonical** — the owner is strongly preferential to restrained pages that let the imagery and design of the site be the proof. The v1 generation is superseded and is not a design source; its copy is also stale (Northern-California positioning, placeholder contacts, Plans presented as client Projects), which contradicts the locked Northern-Alabama-serving-nationwide positioning.

## Considered Options

- **Current sparse generation** — chosen. Correct content and positioning, multi-page structure, restraint as a brand statement.
- **Fuller v1** — rejected. Structurally richer but single-page, and every section's copy would need rewriting.
- **Synthesis** (sparse base + selected v1 sections rebuilt) — rejected. The restraint is deliberate; adding persuasion sections dilutes it.
